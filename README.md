# Word Chain: Web Version

The browser version of the Python word chain game. Climb the ladder from the top word to the bottom word, changing one letter at a time.

## Try it locally

Double-click `index.html`. That's it: no server, no install.

## The files

| File | What it is | Python twin |
|---|---|---|
| `index.html` | The page structure | |
| `style.css` | Colors, layout, the ladder look | |
| `game.js` | All the game logic: graph, BFS, puzzles, the `Game` class | `words.py`, `graph.py`, `puzzle.py`, `game.py` |
| `ui.js` | Draws the ladder and handles clicks and typing | `main.py` |
| `words.js` | The word lists, generated by the script below | |
| `export_words.py` | Turns the `.txt` word lists into `words.js` | |
| `data/popular.txt` | Familiar dictionary words: every word a player can type | |
| `data/enable1.txt` | The full ENABLE dictionary, a bigger and looser alternative | |
| `data/common_short.txt` | Google's most common short words: used for start and target words | |

`game.js` never touches the page and `ui.js` never decides the rules, the same split as the Python version.

## Changing the word lists

Edit or replace the files in `data/`, then run:

```
python export_words.py
```

and reload the page. The script keeps only common words that are also in the allowed list, and skips plurals as start and target words (they're still allowed as moves).

## Putting it online with GitHub Pages (free)

1. Make a free account at github.com if you don't have one.
2. Click **New repository**, name it something like `word-chain`, set it to **Public**, and create it.
3. On the new repo's page, click **uploading an existing file**, drag in everything from this folder (`index.html`, `style.css`, `game.js`, `ui.js`, `words.js`, and the rest), and click **Commit changes**.
4. Go to **Settings > Pages**. Under "Branch," pick `main` and `/ (root)`, then click **Save**.
5. Wait a minute or two and refresh. The page shows your link, which looks like `https://YOUR-USERNAME.github.io/word-chain/`.

To update the live site later, upload the changed files the same way and it redeploys automatically.

## Ideas for next steps

- **The changing target.** In `ui.js`, after every N moves, pick a new target with `WordChain.distancesFrom(graph, game.current)`, choosing a common word a fair distance away, and update `game.target` and `game.par`.
- **Daily puzzle.** Pass `WordChain.seededRandom(seed)` into `makePuzzle`, where the seed comes from today's date (for example `20261027`), so everyone gets the same puzzle each day.
- **Allow more words.** To accept rarer words like "coot," run `python export_words.py --allowed data/enable1.txt`. Hints and answers may then use rarer words too.
- **Stats.** Save games played and par streaks with `localStorage`.
